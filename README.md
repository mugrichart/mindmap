
# 📖 Mind Map

## Hierachical mapping of your learning.

**Mind map** bridges the gap between current AI chatbots interfaces and hierachical learning. It addresses the need of an organized database of your chats for a better and accountable learning.

## 🛠 How It Works
Mind map employs a graph of chats allowing the user to jump through chats:

## Getting Started
### Prerequisites

- Node.js (v24.0.0 or higher)
- MongoDB instance

## Installation
1. Clone the repository
git clone https://github.com/mugrichart/mindmap.git
cd mindmap
2. Install dependencies
cd server
pnpm install
cd ../client
pnpm install
3. Set up Environment Variables
Create a .env file in the root directory
4. Run the application
client: pnpm run dev
server: pnpm start:dev
